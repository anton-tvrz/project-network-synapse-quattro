`FirewallRuleSet` Infrahub schema — the terminal object of the business intent chain (#184), completing the lineage path from application owner to device rule. `binding` is mandatory, so a rule with no owning intent cannot be created. `action` defaults to `deny` so a rule created without an explicit action fails closed. Source and destination prefixes use the `IPNetwork` attribute kind, so an invalid CIDR is rejected at write time rather than reaching a device.
