Infrahub check `validate_orphaned_rules` — flags firewall rules still deployed for a decommissioned `ConnectivityIntent` (#44), the core audit capability of the intent bridge. Because GraphQL filters traverse only one relationship hop, detection is inverted: the `decommissioned_intents` query selects retired intents and walks down to the rules still hanging off them. Each orphan is reported against its `FirewallRuleSet` with the rule name, device, retirement date, and owning team.
